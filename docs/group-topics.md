# Группа с топиками

Режим для ведения переписки с покупателями в **супергруппе Telegram**: у каждого покупателя свой топик, ответы из топика уходят на FunPay от имени магазина.

## Требования

- Супергруппа с включёнными **Темами** (Forum)
- Бот — **администратор** с правом управления темами
- В настройках FunPayWizard: **Группа с топиками** включена

## Включение

`/menu` → **Группа** → включить режим.

## Привязка группы

**Способ 1.** Напиши любое сообщение в группе (от аккаунта администратора бота).

**Способ 2.** `/menu` → **Группа** → **Указать ID группы**.

ID супергруппы обычно вида `-1001234567890`. Если в настройках Telegram видишь только `1234567890`, отправь боту:

```text
-1001234567890
```

## Топики

| Топик | Содержимое |
|-------|------------|
| `👤 Имя покупателя` | Переписка и ответы |
| `⭐ Отзывы и подтверждения заказов` | Отзывы и подтверждения заказов |

В топике покупателя — панель **шаблонов ответа** (добавлять шаблоны только в личке: `/menu` → **Глубокие настройки** → **Шаблоны**).

## Уведомления

В `/menu` → **Уведомления** для **группы** включи нужные типы.

Отзывы и подтверждения заказов при включённой группе идут в **системный топик**, а не дублируются в личку (если тип включён хотя бы в одном чате).

## Первичная настройка

При установке, если выбрал «Да» на шаге группы, бот **дождётся привязки** и только потом завершит настройку и подключится к FunPay.
