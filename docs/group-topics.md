# Группа с топиками

Режим для ведения переписки с покупателями в **супергруппе Telegram**: у каждого покупателя свой топик, ответы из топика уходят на FunPay от имени магазина.

## Требования

- Супергруппа с включёнными **Темами** (Forum)
- Бот — **администратор** с правом управления темами
- В FunPayWizard: `/menu` → **💬 Группа** → режим включён

## Включение и привязка

1. `/menu` → **Группа** → включить **Группа с топиками**
2. Привязать группу одним из способов:
   - написать любое сообщение в группе (от аккаунта администратора бота);
   - **Указать ID группы** в меню бота.

ID супергруппы обычно вида `-1001234567890`. Если в Telegram видишь только `1234567890`, отправь боту:

```text
-1001234567890
```

## Топики

| Топик | Содержимое |
|-------|------------|
| `👤 Имя покупателя` | Переписка, ответы на FunPay, панель шаблонов |
| `Отзывы и подтверждения заказов` | Отзывы и подтверждения заказов (системный, иконка ⭐) |
| **General** | Сервисные уведомления (поднятие лотов, выдача и т.д.), если включены в 🔔 |

В топике покупателя закреплена панель с кнопкой **«Шаблоны»** — по нажатию бот пришлёт список заготовок на выбор. Добавлять и удалять шаблоны можно только в личке: `/menu` → **Глубокие настройки** → **Шаблоны**.

Кнопка **«Ответить»** в уведомлении о заказе (или **«Ответ»** в переписке) открывает топик этого покупателя — создаёт его, если ещё нет. Ссылка на топик приходит в личку с ботом; пиши в топике — текст уйдёт на FunPay. Если режим группы выключен, работает прежний сценарий: бот попросит ввести ответ в личке.

## Уведомления и группа

Настройки **не дублируются** для группы отдельно.

1. `/menu` → **🔔 Уведомления** — включи нужные типы (например, «Новое сообщение», «Поднятие»).
2. Вверху того же меню: **🟢 Все уведомления в группу** — чтобы события шли в супергруппу.

Фильтр **✉️ Сообщения** действует и на топики покупателей: в топик попадает та же отфильтрованная переписка, что и в уведомление в личку. Нужно хотя бы одно сообщение **покупателя** в пачке.

Отзывы и подтверждения при включённом типе и 🟢 «Все в группу» идут в **системный топик**, без дубля в личку.

## Первичная настройка

При установке, если на шаге группы выбрал **Да**, бот **дождётся привязки** группы и только потом завершит настройку и подключится к FunPay.
