# Конфигурация

## Файлы

| Путь | Описание |
|------|----------|
| `.env` | `TELEGRAM_BOT_TOKEN` (приоритет при старте) |
| `configs/_main.cfg` | FunPay, Telegram, приветствия, ЧС, группа |
| `configs/auto_response.cfg` | Команды автоответа |
| `configs/auto_delivery.cfg` | Лоты и автовыдача |
| `storage/cache/` | Уведомления, топики группы, шаблоны, авторизованные пользователи |
| `storage/products/` | Файлы с товарами для выдачи |

Папки `configs/` и `storage/` создаются при первом запуске.

## Основной конфиг (`_main.cfg`)

Секции:

- **FunPay** — golden key, user-agent, автовыдача, поднятие, восстановление лотов
- **Telegram** — токен, `groupTopicsEnabled`, `groupChatId`
- **BlockList** — чёрный список и блокировки
- **Greetings** — приветствие новым покупателям
- **OrderConfirm** / **ReviewReply** — ответы на подтверждение и отзывы
- **NewMessageView** — фильтр уведомлений о сообщениях
- **Proxy** — опционально

Переключатели в боте: `/menu` → **Переключатели**.

## Автоответ (`auto_response.cfg`)

Секция на каждую команду (например `/оплата`):

- текст ответа
- уведомление в Telegram
- переменные: `$username`, `$message`, `$chat_id` и др.

Управление: `/menu` → **Глубокие настройки** → **Автоответ**.

## Автовыдача (`auto_delivery.cfg`)

Привязка лотов FunPay к файлам товаров в `storage/products/`.

Управление: `/menu` → **Глубокие настройки** → **Автовыдача**.

## Загрузка конфигов через бота

`/menu` → **Глубокие настройки** → **Конфиги** — скачать или загрузить `_main.cfg`, автоответ и автовыдачу.

## Переменные в текстах

В автоответе, автовыдаче, приветствии и шаблонах поддерживаются плейсхолдеры (`$username`, `$order_id` и т.д.) — список подсказывается в боте при редактировании.
