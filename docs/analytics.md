# Аналитика

Настраиваемый отчёт по аккаунту FunPay прямо в Telegram.

## Где открыть

`/menu` → **📊 Аналитика**

## Как пользоваться

1. Отметь нужные блоки (🟢 — в отчёте, 🔴 — пропустить).
2. Нажми **▶️ Показать отчёт**.
3. Бот соберёт данные и пришлёт сообщение. Кнопка **Обновить** пересобирает отчёт с тем же набором блоков.

Настройки блоков сохраняются для твоего Telegram-аккаунта (`storage/cache/analytics_prefs.json`).

## Блоки отчёта

| Блок | Содержимое |
|------|------------|
| 💰 Баланс | ID, незавершённые заказы, баланс ₽ / $ / € |
| 🏦 Вывод средств | Доступно сейчас и прогноз по подтверждённым заказам (тяжёлый запрос, по умолчанию выкл.) |
| 📈 Продажи | Количество и сумма за день / неделю / месяц / всё время |
| ↩️ Возвраты | То же по возвратам |
| 📅 Сегодня | Заказы за сегодня, незакрытые, заработок по закрытым |
| 📦 Лоты | Всего и активных лотов в профиле |

Команда `/profile` по-прежнему даёт быструю статистику с кнопкой «Ещё»; **Аналитика** — гибкий отчёт с выбором разделов.
