# Telegram-бот

## Первый вход

1. `/start` — мастер настройки (если конфиг пустой)
2. Введи **секретный ключ** из `configs/_main.cfg` (`Telegram` → `secretKey`), если бот уже настроен на сервере

## Команды

| Команда | Действие |
|---------|----------|
| `/start` | Настройка / меню |
| `/menu` | Панель управления |
| `/profile` | Статистика FunPay |
| `/logs` | Путь к логам |
| `/restart` | Перезапуск |
| `/poweroff` | Остановка (с подтверждением) |

Reply-клавиатура: **Меню**, **Логи**, **Система**, **Рестарт**, **Стоп**.

## Уведомления

`/menu` → **Уведомления** — для текущего чата включаются типы:

- сообщения, команды, заказы
- подтверждение заказа, отзывы
- выдача, поднятие/восстановление лотов
- сводка за день (23:00, только личные чаты)

Для **группы** настрой отдельно после привязки.

## Сообщения (фильтр)

`/menu` → **Сообщения** — что показывать в уведомлениях о переписке:

- включать свои / FunPay / бота
- «Только …» — уведомлять, если в пачке только один тип сообщений

## Глубокие настройки

Автоответ, автовыдача, чёрный список, шаблоны, приветствие, заказ, отзывы, конфиги.

## Поддержка

`/menu` → **Поддержка** — ссылка на [группу поддержки](https://t.me/+Z3Fgq6YXytk1ODEy).

## Ответы на FunPay

- Из уведомления о новом сообщении — кнопки ответа
- Из **группы с топиками** — сообщение в топике покупателя уходит на FunPay
- **Шаблоны** — в личке (меню) и в топике покупателя (только отправка)
