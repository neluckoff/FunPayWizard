# Telegram-бот

## Первый вход

1. `/start` — мастер настройки (если конфиг пустой)
2. Введи **секретный ключ** из `configs/_main.cfg` (`Telegram` → `secretKey`), если бот уже настроен на сервере

## Команды

| Команда | Действие |
|---------|----------|
| `/start` | Настройка / меню |
| `/menu` | Панель управления |
| `/profile` | Краткая статистика FunPay |
| `/logs` | Путь к логам |
| `/restart` | Перезапуск |
| `/poweroff` | Остановка (с подтверждением) |
| `/golden_key` | Сменить golden key FunPay |

Reply-клавиатура: **Меню**, **Логи**, **Система**, **Рестарт**, **Стоп**.

## Уведомления

`/menu` → **🔔 Уведомления**

Если тип включён — событие уходит **в супергруппу** (не в личку). Исключение: при старте в личке может появиться служебное «Telegram-бот запущен» до инициализации FunPay.

Типы событий:

- новые сообщения, команды, заказы
- подтверждение заказа, отзывы
- выдача товара, поднятие / восстановление / отключение лотов
- вечерняя сводка (23:00)

Сервисные события — топик **General**. Отзывы и подтверждения — системный топик **«Отзывы и подтверждения заказов»**. Переписка — **топики покупателей** (см. [group-topics.md](group-topics.md)).

## Сообщения (фильтр переписки)

`/menu` → **🔧 Глубокие настройки** → **✉️ Сообщения**

Работает при включённом типе **«Новое сообщение»** в уведомлениях. Влияет на топики покупателей в группе.

**Сообщения покупателя** всегда учитываются.

**В тексте** — что добавлять в уведомление:

- мои ответы с FunPay
- системные сообщения FunPay
- ответы бота FunPayWizard

**Пинг, если только …** — когда в чате никого, кроме этого источника:

- 🔴 — не присылать уведомление (обычно так и оставляют)
- 🟢 — всё равно присылать

## Аналитика

`/menu` → **📊 Аналитика** — выбор блоков отчёта и кнопка «Показать отчёт».

Подробнее: [analytics.md](analytics.md).

## Глубокие настройки

`/menu` → **🔧 Глубокие настройки**:

- автоответ и автовыдача
- чёрный список
- шаблоны ответов (редактирование только в личке)
- приветствие новым покупателям
- ответ на подтверждение заказа и на отзывы
- загрузка / выгрузка конфигов

## Ответы на FunPay

- Кнопка **«Ответить»** / **«Ответ»** — открывает топик покупателя в группе
- Сообщения в **топике покупателя** уходят на FunPay
- **Шаблоны** — кнопка в топике; редактирование списка — в личке (**Глубокие настройки** → **Шаблоны**)
