# Telegram-бот

## Первый вход

1. `/start` — мастер настройки (если конфиг пустой)
2. Введи **секретный ключ** из `configs/_main.cfg` (`Telegram` → `secretKey`), если бот уже настроен на сервере

## Команды

| Команда | Действие |
|---------|----------|
| `/start` | Настройка / меню |
| `/menu` | Панель управления |
| `/profile` | Краткая статистика FunPay |
| `/logs` | Путь к логам |
| `/restart` | Перезапуск |
| `/poweroff` | Остановка (с подтверждением) |
| `/golden_key` | Сменить golden key FunPay |

Reply-клавиатура: **Меню**, **Логи**, **Система**, **Рестарт**, **Стоп**.

## Уведомления

`/menu` → **🔔 Уведомления**

**Одни настройки** для личных сообщений и для группы: если тип включён — бот может прислать и в ЛС, и в супергруппу (см. переключатель ниже).

Типы событий:

- новые сообщения, команды, заказы
- подтверждение заказа, отзывы
- выдача товара, поднятие / восстановление / отключение лотов
- запуск бота, вечерняя сводка (23:00, только в личку)

### Все уведомления в группу

Первая кнопка в меню (если группа привязана):

- 🟢 — дублировать в супергруппу всё, что включено в списке ниже
- 🔴 — в группу ничего не слать (только личка)

Сервисные события (поднятие лотов, выдача и т.д.) попадают в топик **General**. Отзывы и подтверждения заказов — в системный топик «⭐ Отзывы и подтверждения заказов». Переписка с покупателями — в **личные топики** (см. [group-topics.md](group-topics.md)).

## Сообщения (фильтр переписки)

`/menu` → **🔧 Глубокие настройки** → **✉️ Сообщения**

Работает при включённом типе **«Новое сообщение»** в уведомлениях. Влияет на личку, топики покупателей и текст уведомления.

**Сообщения покупателя** всегда учитываются.

**В тексте** — что добавлять в уведомление:

- мои ответы с FunPay
- системные сообщения FunPay
- ответы бота FunPayWizard

**Пинг, если только …** — когда в чате никого, кроме этого источника:

- 🔴 — не присылать уведомление (обычно так и оставляют)
- 🟢 — всё равно присылать

## Аналитика

`/menu` → **📊 Аналитика** — выбор блоков отчёта и кнопка «Показать отчёт».

Подробнее: [analytics.md](analytics.md).

## Глубокие настройки

`/menu` → **🔧 Глубокие настройки**:

- автоответ и автовыдача
- чёрный список
- шаблоны ответов (редактирование только в личке)
- приветствие новым покупателям
- ответ на подтверждение заказа и на отзывы
- загрузка / выгрузка конфигов

## Ответы на FunPay

- Из уведомления в личке — кнопки быстрого ответа
- Из **топика покупателя** в группе — любое сообщение уходит на FunPay
- **Шаблоны** — отправка из топика; добавление и удаление — в личке (**Глубокие настройки** → **Шаблоны**)
